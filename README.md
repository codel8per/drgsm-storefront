# Dr GSM Storefront

Persian RTL WordPress + WooCommerce storefront for **Dr GSM | دکتر موبایل**.

Public theme/plugin source for `drgsmunlock.com`. This repository is the storefront code only. It does not contain customer data, payment secrets, OTP backends, or a scraped catalogue from any other shop.

## Packages

- `packages/mgsm-rebuild-theme` — block theme v1.3.0
- `packages/mgsm-rebuild-core` — setup plugin (pages, categories, menus, Iran/toman defaults)

## Install

1. WordPress 6.6+ / PHP 8.1+ / official WooCommerce
2. Zip each package folder and upload from wp-admin
3. Activate theme **Dr GSM**, then plugin **Dr GSM Storefront Core**
4. Tools → راه‌اندازی Dr GSM

## What this is not

Do not use this repo to copy another site's users, orders, payment keys, OTP provider, or licensed Elementor/Woodmart files. If you own an existing WooCommerce shop, export from that shop's wp-admin (Products CSV / WordPress export / host backup) and import into this site.
